# 🧤 Thanos Project (Python)

## 📌 Overview

A fun Python project inspired by Thanos.
This notebook randomly deletes files from a folder to simulate "Thanos snapping half the universe".

---

## 🎯 What This Project Does

* Reads files from the `universe` folder
* Randomly selects files
* Deletes files using Python
* Displays the remaining number of files
